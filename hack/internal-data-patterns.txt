# This file ships in the repository, so it holds only patterns that are safe to
# publish: shapes of things (a key header, a token prefix), never actual values.
# Real host names, account names and the like live in

# That is also why the CI job runs with the shipped list only.
#
# Format: name|regex[|skip=<path regex>]
#   - matched case-insensitively against file contents, commit messages and
#     the lines a push adds
#   - a line "-name" switches off a rule of that name loaded earlier
